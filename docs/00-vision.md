# Visión de Plataforma PCI

## Propósito

Construir una plataforma web única para diseñar, validar, simular, implementar, revisar y versionar el Proyecto Curricular Institucional.

## Principio rector

El PCI es un sistema vivo de construcción colectiva. La plataforma debe preservar la memoria de las decisiones, garantizar la trazabilidad curricular y acompañar la mejora continua de cada institución.

## Problema que resuelve

Las instituciones necesitan construir propuestas curriculares complejas sin perder coherencia entre contenidos, horas, niveles, cuatrimestres, orientaciones, versiones y fundamentos pedagógicos.

## Resultado esperado

Una única fuente de verdad institucional capaz de responder qué se enseña, dónde, cuándo, con qué carga horaria, por qué se tomó cada decisión y cómo evolucionó el PCI en el tiempo.

## Principios de producto

- Una sola aplicación.
- Un solo modelo de datos.
- Trazabilidad completa.
- Versiones publicadas inmutables.
- Simulación antes de aplicar cambios.
- Validaciones explicables.
- Decisiones siempre humanas.
- Diseño responsive.
